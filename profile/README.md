# PocketContext

**Your business. Your software. Your agent.**

Business software built around the way you work. We build open-source foundations for applications your AI assistant can operate: finding information, updating records, and carrying out tasks using your data and business rules.

## Explore the projects

| Project | What it provides |
| --- | --- |
| [PocketContext](https://github.com/pocketcontext/pocketcontext) | The shared server, built on PocketBase. Agents read application data through restricted SQL endpoints and make changes through the records API. |
| [DealContext](https://github.com/pocketcontext/dealcontext) | A sales CRM for contacts, pipelines, deals, and follow-ups, with an installable agent skill. |
| [MetaContext](https://github.com/pocketcontext/metacontext) | A catalog of exposed application schemas. Discover tables and columns and document their meaning without reading source application records. |

These projects currently run through coding agents and do not include a conventional application frontend. Each repository documents its setup, requirements, and current scope.
