Business software built around the way your team works. PocketContext provides MIT-licensed applications that people and AI assistants use together to find information, update records, and move work forward—from sales follow-ups to expense approvals. Use these foundations to build workflows around your data and business rules, with self-hosting under your control.

## Applications

| Project | What it provides |
| --- | --- |
| [DealContext](https://github.com/pocketcontext/dealcontext) | A shared sales CRM for contacts, pipelines, deals, and follow-ups, with an installable agent skill. |
| [PeopleContext](https://github.com/pocketcontext/peoplecontext) | HR records, compensation, and reporting relationships, with access filtered by the requester’s identity, reporting chain, and HR role. |
| [TaskContext](https://github.com/pocketcontext/taskcontext) | Shared project and issue tracking with dependencies, comments, evidence references, and change history. People and their agents use the same user identity. |
| [RaiseContext](https://github.com/pocketcontext/raisecontext) | Startup fundraising with investor conversations, introductions, signed commitments, and funds received. |
| [AccountContext](https://github.com/pocketcontext/accountcontext) | Expense evidence, subscriptions, payment matching, reimbursement approvals, and accountant exports. |
| [WikiContext](https://github.com/pocketcontext/wikicontext) | A shared knowledge base: immutable source documents and recordings, cited wiki pages with revision history, and a generated Obsidian export. |
| [ChatContext](https://github.com/pocketcontext/chatcontext) | Team channels, direct messages, and support conversations with threads, protected attachments, and explicit read acknowledgements. Visitors see only their own support conversations. |
| [NotifyContext](https://github.com/pocketcontext/notifycontext) | Colleague notifications and handoffs, with a private inbox, explicit acknowledgements, and an agent skill. |
| [ObserveContext](https://github.com/pocketcontext/observecontext) | Opt-in request tracing and performance analysis, with private operations and an authenticated dashboard. |
| [VaultContext](https://github.com/pocketcontext/vaultcontext) | Client-encrypted file storage with version history, personal and shared vaults, and a portable CLI. |

Applications provide skills for AI assistants alongside browser readers and interfaces suited to each application. Each repository documents its setup, requirements, and current scope.

Try the separate browser demos with synthetic data and predefined actions: [DealContext sales workflow](https://demo.pocketcontext.com/) · [PeopleContext permissions](https://people-demo.pocketcontext.com/). No signup required.

## Foundations

| Project | What it provides |
| --- | --- |
| [PocketContext](https://github.com/pocketcontext/pocketcontext) | The shared server, built on PocketBase. Agents read application data through restricted SQL endpoints and make changes through the records API. |
| [PocketDeploy](https://github.com/pocketcontext/pocketdeploy) | Deployment tooling for OCI servers and ONCE applications, with ownership checks, resumable operations, and encrypted deployment recovery checkpoints. |

[MetaContext](https://github.com/pocketcontext/metacontext), the experimental application-schema catalog, is archived for now and was never deployed.

## Start with your workflow

Have a recurring task, spreadsheet, or software workflow you’d like to improve or automate? [Tell us what you do today and what would make it easier](https://www.pocketcontext.com/#interest).

To get started technically, choose an application, follow its README to install its skill, and authenticate your AI assistant. For questions and contributions, use the relevant project's issue tracker.
